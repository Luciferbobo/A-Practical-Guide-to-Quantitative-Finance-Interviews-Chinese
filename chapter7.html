第7章 算法与数值方法

虽然量化从业者花在编程上的时间百分比因工作职能（如量化分析师/研究员vs量化开发者）和公司文化而异，但典型的量化从业者通常会将部分时间用于通过编程实现模型。因此，编程技能测试通常是量化面试不可分割的一部分。

在很大程度上，量化面试中的编程问题与技术面试中的类似。毫不意外，许多问题是平台或语言特定的。虽然C++和Java仍然主导市场，但我们看到越来越多的语言多样化，如Matlab、SAS、S-Plus和R。由于已有许多书籍和网站专门讨论技术面试，本章不会全面回顾编程问题。相反，它讨论一些在量化面试中最受欢迎的算法问题和数值方法。

7.1 算法

在编程中，算法复杂度分析通常使用渐近分析（Asymptotic Analysis），忽略机器相关的常数，研究运行时间 \(T(n)\)——原始操作（如加法、乘法和比较）的数量——随输入数量 \(n \to \infty\) 的变化。

算法复杂度中三个最重要的记号是大O记号、\(\Omega\) 记号和 \(\Theta\) 记号：

  • \(O(g(n)) = \{f(n)\)：存在正常数 \(c\) 和 \(n_0\)，使得对所有 \(n \geq n_0\)，\(0 \leq f(n) \leq cg(n)\}\)。它是 \(f(n)\) 的渐近上界。
  • \(\Omega(g(n)) = \{f(n)\)：存在正常数 \(c\) 和 \(n_0\)，使得对所有 \(n \geq n_0\)，\(0 \leq cg(n) \leq f(n)\}\)。它是 \(f(n)\) 的渐近下界。
  • \(\Theta(g(n)) = \{f(n)\)：存在正常数 \(c_1\)、\(c_2\) 和 \(n_0\)，使得对所有 \(n \geq n_0\)，\(c_1g(n) \leq f(n) \leq c_2g(n)\}\)。它是 \(f(n)\) 的渐近紧界。

除了记号之外，解释算法复杂度中的两个概念也很重要：

最坏情况运行时间 \(W(n)\)：对任意 \(n\) 个输入的运行时间上界。

平均情况运行时间 \(A(n)\)：如果 \(n\) 个输入是随机选择的，期望运行时间。

对于许多算法，\(W(n)\) 和 \(A(n)\) 具有相同的 \(O(g(n))\)。但正如我们将要讨论的，在某些问题中它们可能不同，其相对重要性往往取决于具体问题。

一个有 \(n\) 个输入的问题通常可以被分割成 \(a\) 个子问题，每个子问题有 \(n/b\) 个输入。这种范式通常称为分治法（Divide-and-Conquer）。如果将问题分割成子问题并合并解所需的原始操作为 \(f(n)\)，运行时间可以表示为递推方程 \(T(n) = aT(n/b) + f(n)\)，其中 \(a \geq 1\)，\(b > 1\)，且 \(f(n) \geq 0\)。

主定理（Master Theorem）是求解递推方程 \(T(n) = aT(n/b) + f(n)\) 紧界的有力工具：

  • 如果 \(f(n) = O(n^{\log_b a - \varepsilon})\)，对某个常数 \(\varepsilon > 0\)，则 \(T(n) = \Theta(n^{\log_b a})\)。
  • 如果 \(f(n) = \Theta(n^{\log_b a}\log^k n)\)，对某个 \(k \geq 0\)，则 \(T(n) = \Theta(n^{\log_b a}\log^{k+1} n)\)。
  • 如果 \(f(n) = \Omega(n^{\log_b a + \varepsilon})\)，对某个常数 \(\varepsilon > 0\)，且 \(af(n/b) \leq cf(n)\)，对某个常数 \(c < 1\)，则 \(T(n) = \Theta(f(n))\)。

二分查找示例：要在有序数组中查找一个元素，算法从 \(a_{\lfloor n/2 \rfloor}\) 开始，每次将搜索元素数量减半，只需进行一次比较。所以 \(a = 1\)，\(b = 2\)，\(f(n) = 1\)。因此二分查找的复杂度为 \(\Theta(\log n)\)。

数字交换

如何在不使用额外存储空间的情况下交换两个整数 \(i\) 和 \(j\)？

💡 点击查看解答

比较和交换是许多算法的基本操作。最常见的交换技术使用临时变量，但在这个问题中不允许使用。一个简单的数学方法是先存储 \(i\) 和 \(j\) 的和，然后提取各自的值：

void swap(int &i, int &j) {
    i = i + j;    //存储i和j的和
    j = i - j;    //将j变为i的值
    i = i - j;    //将i变为j的值
}

另一种方案使用按位异或（XOR）运算，利用 \(x \oplus x = 0\) 和 \(0 \oplus x = x\) 的事实：

void swap(int &i, int &j){
    i = i ^ j;
    j = j ^ i;   //j = i ^ (j ^ i) = i
    i = i ^ j;   //i = (i ^ j) ^ i = j
}

唯一元素

如果给你一个已排序的数组，你能写一些代码来提取数组中的唯一元素吗？例如，如果数组是[1, 1, 3, 3, 3, 5, 5, 5, 9, 9, 9, 9]，唯一元素应该是[1, 3, 5, 9]。

💡 点击查看解答

设 \(a\) 为一个有 \(n\) 个元素的已排序数组。每当我们遇到一个新元素 \(a_i\) 时，它的值与前一个元素不同（\(a_i \neq a_{i-1}\)）。利用这个性质我们可以轻松提取唯一元素：

template <class T> vector<T> unique(T a[], int n) {
    vector<T> vec; // 使用vector避免大小调整问题
    vec.reserve(n); //预留空间避免重新分配
    vec.push_back(a[0]);
    for(int i=1; i<n; ++i) {
        if(a[i] != a[i-1])
            vec.push_back(a[i]);
    }
    return vec;
}

霍纳算法

编写一个算法计算 \(y = A_0 + A_1x + A_2x^2 + A_3x^3 + \cdots + A_nx^n\)。

💡 点击查看解答

朴素方法分别计算多项式的每个分量然后相加，需要 \(O(n^2)\) 次乘法。我们可以使用霍纳算法（Horner's Algorithm）将乘法次数减少到 \(O(n)\)。

该算法将原始多项式表示为：

\[y = (((A_nx + A_{n-1})x + A_{n-2})x + \cdots + A_1)x + A_0\]

然后依次计算：\(B_n = A_n\)，\(B_{n-1} = B_nx + A_{n-1}\)，...，\(B_0 = B_1x + A_0\)。我们有 \(y = B_0\)，最多需要 \(n\) 次乘法。

移动平均

给定一个长度为 \(m\) 的大数组 \(A\)，你能开发一个高效算法来构建另一个包含原始数组 \(n\) 元素移动平均的数组吗？

（\(B_1, \cdots, B_{n-1} = NA\)，\(B_i = (A_{i-n+1} + A_{i-n+2} + \cdots + A_i)/n\)，\(\forall i = n, \cdots, m\)）

💡 点击查看解答

当我们计算下一个 \(n\) 个连续数字的移动平均时，可以重用之前计算的移动平均。只需将该平均值乘以 \(n\)，减去该移动平均中的第一个数字，然后加上新数字，就得到新的和。

S = A[1] + ... + A[n]; B[n] = S/n;
for (i = n+1 to m) {
    S = S - A[i-n] + A[i];
    B[i] = S/n;
}

排序算法

你能解释三种排序算法来对 \(n\) 个不同的值 \(A_1, \cdots, A_n\) 进行排序，并分析每种算法的复杂度吗？

💡 点击查看解答

插入排序（Insertion Sort）

插入排序使用增量方法。假设我们已经排好了子数组A[1, ..., i-1]。我们将元素 \(A_i\) 插入A[1, ..., i-1]中的适当位置，得到已排序子数组A[1, ..., i]。

每步的期望比较次数为 \(i/2\)，最坏情况比较次数为 \(i\)。所以：

\[A(n) = \Theta\left(\sum_{i=1}^{n}i/2\right) = \Theta(n^2), \quad W(n) = \Theta\left(\sum_{i=1}^{n}i\right) = \Theta(n^2)\]

归并排序（Merge Sort）

归并排序使用分治范式。它将数组分成两个子数组，每个有 \(n/2\) 个元素，递归排序后合并。

mergesort(A, beginindex, endindex)
    if beginindex < endindex
        then centerindex ← (beginindex + endindex)/2
            merge1 ← mergesort(A, beginindex, centerindex)
            merge2 ← mergesort(A, centerindex + 1, endindex)
            merge(merge1, merge2)

运行时间递推函数：

\[T(n) = \begin{cases} 2T(n/2) + \Theta(n), & \text{if } n > 1 \\ 1, & \text{if } n = 1 \end{cases}\]

应用主定理，\(a = 2\)，\(b = 2\)，\(f(n) = \Theta(n)\)，所以 \(T(n) = \Theta(n\log n)\)。

快速排序（Quicksort）

快速排序从序列中选择一个元素 \(A_i\)，将所有其他值与之比较。小于 \(A_i\) 的放入左边子数组，大于的放入右边子数组，然后递归。

最坏情况：当数组已排序且总选择第一个元素时，\(W(n) = \Theta(n^2)\)。

平均情况：设 \(\tilde{A}_p\) 和 \(\tilde{A}_q\) 被比较的概率为 \(P(p,q) = \frac{2}{q-p+1}\)，则：

\[A(n) = \sum_{q=2}^{n}\sum_{p=1}^{q-1}\frac{2}{q-p+1} = \Theta(n\log n)\]

虽然理论上快速排序在最坏情况下可能比归并排序慢，但它在实际中往往和归并排序一样快，甚至更快。

随机排列

A. 如果你有一个随机数生成器，你如何洗一副52张牌使得每种排列都等可能？

💡 点击查看解答

方法一：排序随机排列。为每张牌分配一个随机数，然后按照分配的随机数顺序排列牌。复杂度为 \(\Theta(n\log n)\)。

方法二：Knuth洗牌（复杂度 \(\Theta(n)\)）：

for (i = 1 to n)
    swap(A[i], A[Random(i, n)])

其中Random(i, n)是来自 \(i\) 和 \(n\) 之间离散均匀分布的随机数。

直觉：在第一步中，\(n\) 张牌中的每张都有相同概率被选为第一张牌；在第二步中，剩余 \(n-1\) 张牌中的每张都有相同概率被选为第二张牌；依此类推。每个有序序列都有 \(1/n!\) 的概率。

B. 你有一个由字符组成的文件。文件中的字符可以顺序读取，但文件长度未知。你如何选取一个字符使得文件中每个字符被选中的概率相等？

💡 点击查看解答

从选第一个字符开始。如果有第二个字符，以概率1/2保留第一个字符，以概率1/2用第二个字符替换。如果有第三个字符，以概率2/3保留选择，以概率1/3替换。

一般地，设 \(C_n\) 为扫描 \(n\) 个字符后的选择，当第 \((n+1)\) 个字符存在时：

  • 保留选择的概率为 \(\frac{n}{n+1}\)
  • 切换到第 \((n+1)\) 个字符的概率为 \(\frac{1}{n+1}\)

使用归纳法可证明：如果有 \(m\) 个字符，每个字符被选中的概率为 \(1/m\)。

搜索算法

A. 设计一个算法，使用不超过 \(3n/2\) 次比较来找到 \(n\) 个数的最小值和最大值。

💡 点击查看解答

将元素分成 \(n/2\) 对，比较每对中的元素，将较小的放入组 \(A\)，较大的放入组 \(B\)（需 \(n/2\) 次比较）。

由于最小值必在组 \(A\) 中，最大值必在组 \(B\) 中，只需找到 \(A\) 中的最小值和 \(B\) 中的最大值，每个需要 \(n/2-1\) 次比较。总比较次数最多为 \(3n/2\)。

B. 给你一个数字数组。从数组开始到某个位置，所有元素都是零；之后所有元素都是非零的。如果你不知道数组大小，如何找到第一个非零元素的位置？

💡 点击查看解答

从第1个元素开始；如果是零，检查第2个元素；如果仍是零，检查第4个元素...重复直到第 \(2^i\) 个元素是非零的。然后在 \(2^{i-1}\) 和 \(2^i\) 之间进行二分查找。

如果第一个非零元素在位置 \(n\)，算法复杂度为 \(\Theta(\log n)\)。

C. 你有一个方形数字网格。每行从左到右递增，每列从上到下递增。设计算法在网格中查找一个给定数字。

💡 点击查看解答

设 \(A\) 为 \(n \times n\) 矩阵，\(x\) 为要查找的数字。从最后一列的顶部开始从上到下搜索。

  • 如果 \(A_{i,n} < x < A_{i+1,n}\)，排除前 \(i\) 行，沿第 \((i+1)\) 行从右向左搜索
  • 如果 \(A_{i+1,j+1} > x > A_{i+1,j}\)，排除第 \(j+1, \cdots, n\) 列，沿第 \(j\) 列向下搜索
  • 如此交替行列搜索，直到找到 \(x\) 或确定其不存在

使用这个算法，搜索最多需要 \(2n\) 步，复杂度为 \(O(n)\)。

斐波那契数

考虑以下计算斐波那契数的C++程序。如果对某个大的 \(n\)，计算Fibonacci(n)需要100秒，那么计算Fibonacci(n+1)需要多长时间？这个算法高效吗？你会如何计算斐波那契数？

int Fibonacci(int n)
{
    if (n <= 0)
        return 0;
    else if (n == 1)
        return 1;
    else
        return Fibonacci(n-1) + Fibonacci(n-2);
}
💡 点击查看解答

斐波那契数定义为：\(F_0 = 0\)，\(F_1 = 1\)，\(F_n = F_{n-1} + F_{n-2}\)，\(\forall n \geq 2\)。

封闭形式解：

\[F_n = \frac{(1+\sqrt{5})^n - (1-\sqrt{5})^n}{2^n\sqrt{5}}\]

从程序可知 \(T(0) = 1\)，\(T(1) = 1\)，\(T(n) = T(n-1) + T(n-2) + 1\)。运行时间正比于斐波那契数序列。

对于大的 \(n\)：\(\frac{T(n+1)}{T(n)} \approx \frac{\sqrt{5}+1}{2}\)。所以计算Fibonacci(n+1)的时间约为 \(\frac{\sqrt{5}+1}{2} \times 100 \approx 162\) 秒。

递归算法具有指数复杂度 \(\Theta\left(\left(\frac{\sqrt{5}+1}{2}\right)^n\right)\)，非常低效。

更高效的方法

迭代法 \(\Theta(n)\)：按顺序计算 \(F_0, F_1, \cdots, F_n\)。

递归平方法 \(\Theta(\log n)\)：利用矩阵关系：

\[\begin{bmatrix} F_{n+1} & F_n \\ F_n & F_{n-1} \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}^n\]

设 \(A = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}\)，使用分治计算 \(A^n\)：

\[A^n = \begin{cases} A^{n/2} \times A^{n/2}, & \text{if } n \text{ is even} \\ A^{(n-1)/2} \times A^{(n-1)/2} \times A, & \text{if } n \text{ is odd} \end{cases}\]

两个 \(2 \times 2\) 矩阵的乘法复杂度为 \(\Theta(1)\)，所以 \(T(n) = T(n/2) + \Theta(1)\)，应用主定理得 \(T(n) = \Theta(\log n)\)。

最大连续子数组

假设你有一个长度为 \(n\) 的一维数组 \(A\)，包含正数和负数。设计一个算法找到任意连续子数组 \(A[i, j]\) 的最大和：\(V(i, j) = \sum_{x=i}^{j}A[x]\)，\(1 \leq i \leq j \leq n\)。

💡 点击查看解答

几乎所有交易系统都需要这样一个算法来计算最大上涨（Maximum Run-up）或最大回撤（Maximum Drawdown）。

\(O(n^2)\) 算法

从头开始依次计算 \(V(i, j)\)：\(V(i, i) = A[i]\)，\(V(i, j) = V(i, j-1) + A[j]\)（当 \(j > i\)）。

\(O(n)\) 算法

定义 \(T(i) = \sum_{x=1}^{i}A[x]\) 且 \(T(0) = 0\)，则 \(V(i, j) = T(j) - T(i-1)\)。对于固定的 \(j\)，当 \(T(i-1)\) 最小化时，\(V(i, j)\) 最大化。

T = A[1]; V_max = A[1]; T_min = min(0, T)

For j = 2 to n
{   T = T + A[j];
    If T - T_min > V_max then V_max = T - T_min;
    If T < T_min, then T_min = T;
}
Return V_max;

C++实现：

double maxSubarray(double A[], int len, int &i, int &j)
{
    double T=A[0], Vmax=A[0];
    double Tmin = min(0.0, T);
    for(int k=1; k<len; ++k)
    {
        T += A[k];
        if (T-Tmin > Vmax) {Vmax=T-Tmin; j=k;}
        if (T<Tmin) {Tmin = T; i = (k+1<j)? (k+1):j;}
    }
    return Vmax;
}

示例：

double A[]={1.0, 2.0, -5.0, 4.0, -3.0, 2.0, 6.0, -5.0, -1.0};
int i = 0, j = 0;
double Vmax = maxSubarray(A, sizeof(A)/sizeof(A[0]), i, j);

结果：\(V_{max} = 9\)，\(i = 3\)，\(j = 6\)。子数组为 [4.0, -3.0, 2.0, 6.0]。

7.2 二的幂

世界上只有10种人——懂二进制的和不懂的。计算机使用二进制（base-2）数字系统运行。与十进制数字0-9不同，每个位（bit）只有两个可能的值：0和1。数字的二进制表示具有一些有趣的性质，在实践中被广泛探索。

2的幂判断

如何判断一个整数是否是2的幂？

💡 点击查看解答

任何整数 \(x = 2^n\)（\(n \geq 0\)）只有一个位被设为1。例如，\(8 (= 2^3)\) 表示为 0...01000。

同样，\(2^n - 1\) 的右边 \(n\) 位全部设为1。例如，7表示为 0...00111。

所以 \(2^n\) 和 \(2^n - 1\) 没有共同的位。因此：

// 判断x是否为2的幂
bool isPowerOfTwo(int x) {
    return (x > 0) && ((x & (x - 1)) == 0);
}

\(x \& (x-1) = 0\) 即为判断条件（其中 & 是按位AND运算符）。

乘以7

给出一种不使用乘法(*)运算符将整数乘以7的快速方法？

💡 点击查看解答
// (x << 3) - x
// 其中 << 是位左移运算符
// x << 3 等价于 x * 8
// 所以 (x << 3) - x = x * 8 - x = x * 7
int multiplyBy7(int x) {
    return (x << 3) - x;
}

概率模拟

给你一枚公平硬币。你能设计一个使用公平硬币的简单游戏，使得你的获胜概率为 \(p\)，\(0 < p < 1\)？

💡 点击查看解答

关键认识到 \(p \in (0,1)\) 可以表示为二进制数，每一位都可以用公平硬币模拟。

首先，将概率 \(p\) 表示为二进制数：

\[p = 0.p_1p_2\cdots p_n = p_1 \cdot 2^{-1} + p_2 \cdot 2^{-2} + \cdots + p_n \cdot 2^{-n}, \quad p_i \in \{0, 1\}\]

然后开始抛硬币，将正面计为1，反面计为0。设 \(s_i\) 为第 \(i\) 次抛掷的结果：

算法：
1. 将 p 表示为二进制: p = 0.p₁p₂...pₙ
2. 从 i = 1 开始抛硬币，得到 sᵢ
3. 比较 pᵢ 与 sᵢ：
   - 如果 sᵢ < pᵢ（即 sᵢ=0, pᵢ=1）→ 赢，停止
   - 如果 sᵢ > pᵢ（即 sᵢ=1, pᵢ=0）→ 输，停止
   - 如果 sᵢ = pᵢ → 继续抛第 i+1 次
4. 若序列有限且到最后 sₙ = pₙ → 输

某些 \(p\) 值（如1/3）表示为二进制时是无限序列。随着 \(i\) 增加，达到 \(s_i \neq p_i\) 的概率趋向1。

毒酒

你有1000瓶酒准备在生日派对上使用。派对前20小时，酒庄说有一瓶被下了毒。你有10只实验鼠可以用来测试。毒性很强，任何量的毒酒都会在恰好18小时后杀死老鼠。有没有一种确定的方法在派对前用10只老鼠找到被下毒的瓶子？

💡 点击查看解答

由于症状要到18小时后才显现，不能依次测试。但二分查找的思想仍然适用。

关键洞察：1到1000之间的所有整数都可以用10位二进制格式表示（\(2^{10} = 1024 > 1000\)）。

方法：
1. 将每瓶酒用10位二进制编号
   例如：第1000瓶 = 1111101000

2. 让老鼠k（k=1,...,10）从第k位为1的所有酒中各喝一口
   - 老鼠1：喝所有第1位(最低位)为1的酒
   - 老鼠2：喝所有第2位为1的酒
   - ...
   - 老鼠10：喝所有第10位(最高位)为1的酒

3. 18小时后观察结果：
   - 将老鼠从最高位到最低位排列
   - 活鼠 → 0，死鼠 → 1
   - 得到的二进制数即为有毒瓶子的编号

示例：如果第6、7、9号鼠死了而其他都活着，排列得到 0101100000，有毒瓶子编号为 \(2^8 + 2^6 + 2^5 = 352\)。

7.3 数值方法

许多金融工具的价格没有封闭形式的解析解。这些金融工具的估值依赖于各种数值方法。本节讨论蒙特卡洛模拟（Monte Carlo Simulation）和有限差分方法（Finite Difference Methods）的应用。

蒙特卡洛模拟

蒙特卡洛模拟是一种使用具有适当概率的随机数作为输入来迭代评估确定性模型的方法。对于衍生品定价，它模拟大量标的资产价格路径，计算每条路径衍生品的折现收益，并取平均得到衍生品价格。其有效性依赖于大数定律。

A. 解释如何使用蒙特卡洛模拟对欧式看涨期权定价？

💡 点击查看解答

假设股票价格遵循几何布朗运动，将时间 \([t, T]\) 分成 \(N\) 个等间隔时间步，\(\Delta t = \frac{T-t}{N}\)。

在风险中性概率下模拟股票价格路径：

\[S_i = S_{i-1} \cdot e^{(r-\sigma^2/2)\Delta t + \sigma\sqrt{\Delta t}\,\varepsilon_i}\]

其中 \(\varepsilon_i\) 是独立同分布标准正态随机变量。

假设模拟 \(M\) 条路径，每条路径产生到期股价 \(S_{T,k}\)，欧式看涨期权的估计价格为：

\[C = e^{-r(T-t)}\frac{\sum_{k=1}^{M}\max(S_{T,k} - K, 0)}{M}\]

B. 如果计算机只能生成[0,1]均匀分布随机变量，如何生成服从 \(N(\mu, \sigma^2)\) 的随机变量？

💡 点击查看解答

分两步解决：

  1. 从均匀随机数生成 \(x \sim N(0,1)\) 的随机变量
  2. 将 \(x\) 缩放为 \(\mu + \sigma x\) 生成 \(N(\mu, \sigma^2)\) 随机变量

逆变换方法

对于CDF为 \(F\) 的连续随机变量 \(X\)，可通过 \(X = F^{-1}(U)\) 生成，其中 \(U \sim \text{Uniform}(0,1)\)。但标准正态的反函数无解析解。

接受-拒绝方法

使用指数分布 \(g(x) = e^{-x}\) 作为辅助分布（其逆CDF有解析解 \(x = -\log(1-u)\)）：

\[\frac{f(x)}{g(x)} = \sqrt{\frac{2}{\pi}}e^{x-x^2/2} \leq \sqrt{\frac{2}{\pi}}e^{1/2} \approx 1.32 = M\] 
接受-拒绝算法：
1. 抽样步骤：从 g(y) 生成随机变量 y，从 U(0,1) 生成 v
2. 接受/拒绝步骤：
   如果 v ≤ f(y)/(M·g(y))，接受 x = y
   否则，重复步骤1
3. 最终：result = μ + σ·x

C. 你能解释一些方差缩减技术吗？

💡 点击查看解答

蒙特卡洛估计量 \(\bar{Y} = \frac{1}{M}\sum_{i=1}^{M}Y_i\) 的方差为 \(Var(\bar{Y}) = \sigma/\sqrt{M}\)。以下技术可减少方差：

1. 对偶变量（Antithetic Variable）

对每组 \(\varepsilon_i\)，同时计算 \(Y(\varepsilon_1, \cdots, \varepsilon_N)\) 和 \(Y(-\varepsilon_1, \cdots, -\varepsilon_N)\)。当两者负相关时方差减小。

2. 矩匹配（Moment Matching）

重新缩放样本使样本的矩（均值和方差）匹配所需的总体矩。

3. 控制变量（Control Variate）

如果有密切相关且有解析解的衍生品 \(Y\)，用相同随机序列对 \(X\) 和 \(Y\) 定价，估计 \(X\) 为 \(\hat{X} + (Y - \hat{Y})\)。

4. 重要性抽样（Importance Sampling）

\[E_{f(x)}[h(x)] = \int\frac{h(x)f(x)}{g(x)}g(x)dx = E_{g(x)}\left[\frac{h(x)f(x)}{g(x)}\right]\]

如果 \(\frac{h(x)f(x)}{g(x)}\) 比 \(h(x)\) 方差更小，则更高效。适用于深度虚值期权定价。

5. 低差异序列（Low-discrepancy Sequence）

使用确定性序列代替随机样本，可使收敛速率达到 \(1/M\)。

D. 如果一个期权没有封闭形式定价公式，如何估计它的Delta和Gamma？

💡 点击查看解答

对三个起始价格 \(S - \delta S\)、\(S\) 和 \(S + \delta S\) 运行蒙特卡洛模拟，得到对应期权价格 \(f(S - \delta S)\)、\(f(S)\) 和 \(f(S + \delta S)\)。

估计的Delta：

\[\Delta = \frac{f(S + \delta S) - f(S - \delta S)}{2\delta S}\]

估计的Gamma：

\[\Gamma = \frac{f(S + \delta S) - 2f(S) + f(S - \delta S)}{(\delta S)^2}\]

为减少方差，最好使用相同的随机数序列来估计三个价格。

E. 如何使用蒙特卡洛模拟估计 \(\pi\)？

💡 点击查看解答

在单位正方形中随机选取点（\(x, y\) 为0到1间独立均匀随机变量），确定落在单位圆内的点的比例：

\[\hat{p} = \frac{\text{满足 } x_i^2 + y_i^2 \leq 1 \text{ 的点数}}{\text{总点数}} = \frac{\pi/4}{1} \Rightarrow \hat{\pi} = 4\hat{p}\] 
估计π的算法：
1. 设 count = 0, total = M
2. For k = 1 to M:
     生成 x ~ U(0,1), y ~ U(0,1)
     If x² + y² ≤ 1 then count = count + 1
3. π̂ = 4 × count / M

用1,000,000个点进行1,000次模拟，\(\pi\) 的平均估计为3.1416，标准差为0.0015。

有限差分方法

有限差分方法通过离散化时间和标的证券价格，数值求解微分方程来估计衍生品价格。将BSM方程转化为热扩散方程后，通过建立 \(x\) 和 \(\tau\) 的网格并使用边界条件，递归计算各节点上的 \(u\) 值。

A. 你能简要解释有限差分方法吗？

💡 点击查看解答

将 \(\tau\) 的范围 \([0, T]\) 分成 \(N\) 个离散区间（\(\Delta\tau = T/N\)），将 \(x\) 的范围 \([x_0, x_J]\) 分成 \(J\) 个离散区间（\(\Delta x = (x_J - x_0)/J\)）。

显式差分方法

使用时间 \(\tau_n\) 的前向差分和 \(x_j\) 处的二阶中心差分：

\[\frac{u_j^{n+1} - u_j^n}{\Delta\tau} = \frac{u_{j+1}^n - 2u_j^n + u_{j-1}^n}{(\Delta x)^2}\]

整理得：

\[u_j^{n+1} = \alpha u_{j-1}^n + (1-2\alpha)u_j^n + \alpha u_{j+1}^n, \quad \alpha = \frac{\Delta\tau}{(\Delta x)^2}\]

隐式差分方法

使用时间 \(\tau_{n+1}\) 的后向差分：

\[\frac{u_j^{n+1} - u_j^n}{\Delta\tau} = \frac{u_{j+1}^{n+1} - 2u_j^{n+1} + u_{j-1}^{n+1}}{(\Delta x)^2}\]

Crank-Nicolson方法

使用时间 \((\tau_n + \tau_{n+1})/2\) 的中心差分：

\[\frac{u_j^{n+1} - u_j^n}{\Delta\tau} = \frac{1}{2}\left(\frac{u_{j+1}^n - 2u_j^n + u_{j-1}^n}{(\Delta x)^2} + \frac{u_{j+1}^{n+1} - 2u_j^{n+1} + u_{j-1}^{n+1}}{(\Delta x)^2}\right)\]

B. 使用显式有限差分方法时，时间维度步数过多还是空间维度步数过多更糟糕？

💡 点击查看解答

显式方法的稳定性条件为：

\[1-2\alpha > 0 \Rightarrow \frac{\Delta\tau}{(\Delta x)^2} < \frac{1}{2}\]

空间维度步数过多更糟糕。

  • 小的 \(\Delta\tau\)（多时间步）是可取的，有利于稳定性
  • 小的 \(\Delta x\)（多空间步）可能使 \(\Delta\tau/(\Delta x)^2 > 1/2\)，导致不稳定

相比之下，隐式差分方法始终稳定且收敛，不受此限制。
